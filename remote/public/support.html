Support

Service: Page2AI MCP hosted endpoint (page2ai-mcp-remote.vercel.app).

Get help / report a bug

Open an issue at github.com/igorsaevets/page2ai-mcp/issues. Helpful details: the URL you converted, the client you used (ChatGPT, Claude, Codex, an SDK), the tool arguments, and what you expected vs. what you got. Issues are the canonical channel — they are public, searchable, and get answered.

Security reports

Please use GitHub private vulnerability reporting — not a public issue — for anything exploitable.

Documentation

Setup guides for every client, tool parameters and the local-install option: igorsaevets.github.io/page2ai-docs. Endpoint: https://page2ai-mcp-remote.vercel.app/api/mcp (Streamable HTTP).

Known limits

Public pages only (no logins, no paywalls, no private networks); 10 MB response cap; per-IP rate limits; JavaScript-only pages may extract poorly — the browser extension handles those.
