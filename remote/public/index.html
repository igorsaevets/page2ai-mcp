Page2AI MCP — hosted endpoint

This is the hosted (Streamable HTTP) variant of the Page2AI MCP server: one tool, page_to_markdown, which fetches a public web page and converts it to clean Markdown for LLM context.

MCP endpoint: POST /api/mcp (Model Context Protocol, Streamable HTTP transport).

Privacy

Requests to this hosted endpoint transit this server: the URL you ask it to convert is fetched from here. No accounts, no tracking cookies; operational logs are Vercel platform defaults. If you want zero egress to any third party, run the same server locally instead — npx -y page2ai-mcp — it is the same code and stays entirely on your machine.

Rate limits apply (per-IP). The fetcher blocks private network ranges, loopback and cloud metadata endpoints, caps responses at 10 MB and enforces timeouts.
